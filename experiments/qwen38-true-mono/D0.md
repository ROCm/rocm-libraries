**D0.8 amendment (WP1 fix round, 2026-10-31; `wave1/WP1.md` Verification and Fix round).** A deadline poll that times out returns the stale payload. That payload can be the previous layer's correct output (in Path B from the previous launch, in Path A from the previous loop iteration), so a broken tag invariant can be numerically invisible: on hardware both ptoy paths gave 12/12 correct layers with every `g` poll timed out, and whether they do is a race between equal deadlines that changes from run to run. Rule: **any build with a deadline edge must have its launch-fatal word checked by the host after every launch or every graph replay** (`persist.sync.check_launch`; the word is a sticky OR, so one check per replay covers every launch in it). Validation and gate runs of Path B layer kernels build every edge with a deadline and `err_arg` (`persist.knobs.require_launch_fatal`). Without deadline polls a broken tag hangs, which is visible; whether served builds keep deadline edges is a WP3a timing question (a losing lever stays a knob).
