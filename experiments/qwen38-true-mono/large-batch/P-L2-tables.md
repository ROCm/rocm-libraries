# P-L2 tables (ratios only)

Companion of `P-L2.md`. Every ratio is a per-round median of (arm per-layer time) / (grid arm per-layer time) of the same
job, skew and cell, over 20 shuffled rounds (16 in the screen); verdicts by DESIGN 9.1's win rule against the two
controls (`grid#2` second graph, `grid_rc` recompiled copy). Absolute times: `hackathon-prep/private-perf/qwen38-true-mono/large-batch/P-L2.md`.
Runs: g = job 68235854 (n01-09, bus 65), h = job 68235853 (n07-17, bus 05) [final arm set incl. the combination winners];
d = job 68235788 (n01-09, bus 15), e = job 68235789 (n07-17, bus 15) [base arm set]; f = job 68235804 (n01-09, bus 65)
[combination screen]. All on MI355X, q38 venv (torch 2.12 + ROCm 7.2 COMGR, llvm22).

Cells: `tp<TP>:<rows>:<plan>` (`ft` = FlyTape's phase list, `lb` = DESIGN-LB's stage list, a trailing `0` = the null
plan: same graph, zero weight bytes). Arms: `grid` striped grid barrier before every stage; `tile` flags of the read set
(drain publish); `tile_w` per-wave flags; `tile_c` counted publish; `tile_p` poll pause `s_sleep 1`; `a2a` flags of every
unit of the previous stage (mailbox all-to-all), `a2a_w` / `a2a_c` its publish variants; `mix90` / `mix40` grid barrier on
edges reading >= 0.9 / 0.4 of the previous stage, flags elsewhere (counted publish), `mix90d` drain publish, `mix90l` /
`mix40l` drain + lazy publish; `m.<pub d|w>.<lazy 0|1>.<pause n|s>.<thr>` the combination arms (sync=mix); `none` no
sync at all (timing floor, numerics racy by construction).
