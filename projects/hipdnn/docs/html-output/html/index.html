hipDNN documentation#

hipDNN (Deep Neural Network) is a plugin-based deep learning library that provides graph-based operation support through various backend plugins. Each plugin implements specific operations with support for different datatypes, layouts, and features. hipDNN allows developers to run deep learning workloads on ROCm and AMD GPUs while maintaining compatibility with NVIDIA’s cuDNN API.

The component public repository is located at ROCm/rocm-libraries.
