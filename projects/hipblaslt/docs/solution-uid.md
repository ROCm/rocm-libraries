# Solution UID foundation

`SolutionUID` is a 64-bit identifier for a hipBLASLt/TensileLite solution
record. An identifier persisted in logic YAML stays stable across library
rebuilds. Library generation decodes that identifier and stores it in runtime
metadata. When the YAML has no UID, generation assigns one for that build
without updating the YAML; rebuilding can produce a different UID. Loading
older prebuilt metadata with no UID leaves the runtime value at zero.
Runtime selection by UID is a later migration step.

Geko assigns a fresh UID to solutions copied into `final_libs` or `full_libs`,
including copies from Origami. These are new records, even when they describe
the same GPU kernel. When `TensileMergeLibrary` reuses an existing Equality
solution with the same `SolutionNameMin`, it retains the Equality record's UID.

## Identifier format

```text
| 40 bits: milliseconds since 2026-01-01 UTC | 24 bits: OS randomness |
```

UIDs are generated by
`tensilelite/tensilelite/Common/SolutionIdGen.py`. Internally, a UID remains an
unsigned 64-bit integer. Human-readable files and command-line output use an
unpadded base62 representation:

- the frozen alphabet is `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz`;
- writers use the `0u` prefix; readers also accept `0U`;
- leading zero digits are forbidden, except that zero is written as `0u0`;
- values larger than `2^64 - 1` are rejected.

For example, decimal UID `200` is represented as `0u3E`. A UID is stored as
the optional, unquoted `SolutionUID` field immediately after the local
`SolutionIndex` in dict-format logic YAML:

```yaml
- SolutionIndex: 0
  SolutionUID: 0u3E
```

Decoding is explicit: a reader calls ``decode_solution_uid`` and then uses the
unsigned 64-bit value for identity, comparison, and mapping. New dict-format
files from LibraryLogic (tuning) and TensileMergeLibrary keep `SolutionUID`
immediately after `SolutionIndex`. Legacy list-format files keep keys in their
existing alphabetical layout, so `SolutionUID` follows `SolutionNameMin`.

## Regenerate a UID

To replace one solution's UID after a duplicate is reported:

```bash
cd projects/hipblaslt/tensilelite
python3 -m tensilelite.TensileGenerateUID path/to/logic.yaml --index 5 --inplace
```

`--index` is the solution's local `SolutionIndex` in that YAML file. Without
`--inplace`, the command prints the new canonical `0u` UID without modifying
the file.

One Tensile process, one Geko generation, and one library merge each reject a
UID collision inside that run. Uniqueness across the shipped logic tree remains
the ``library-uniqueness`` check. Runtime selection by UID is a later step.
