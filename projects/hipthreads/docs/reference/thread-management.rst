*******************************
Thread management API
*******************************

The thread management API provides the core GPU wthread lifecycle: launch, join, detach, and query wthread and fiber identity.
The ``hip::this_thread`` namespace contains free functions for querying the calling wthread's ID, fiber ID, and SIMD width, and for yielding or sleeping.
The callable passed to a ``hip::wthread`` constructor must be a ``__device__`` function.
The ``max_width()`` constructor overload lets you use SIMD multi-fiber execution.
``hip::thread`` is a deprecated alias for ``hip::wthread``.

For background on the persistent scheduler, virtual cores, and multi-fiber execution, see the :ref:`execution model <execution-model>`.

********************

``hip::wthread::id`` is a typedef for ``hip::__thread_id``.
