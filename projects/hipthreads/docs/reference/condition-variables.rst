****************************
Condition variable API
****************************

hipThreads provides device-side condition variables that spin while waiting.
``hip::condition_variable_any()`` works with any lockable type, including ``hip::spin_mutex`` through a ``hip::unique_lock``.
``hip::spin_condition_variable`` busy-waits without yielding.
``hip::pseudo_condition_variable`` busy-waits and periodically calls ``hip::this_thread::pseudo_yield()``.
Time-based waits with ``wait_for()`` and ``wait_until()`` aren't enabled in the current release.
For conceptual background, see :doc:`/conceptual/synchronization-primitives`.
For the mutex types used with condition variables, see :doc:`/reference/mutual-exclusion`.
