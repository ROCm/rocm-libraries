*****************************************
Integrate hipThreads into a CMake project
*****************************************

Follow these instructions to configure a CMake project that finds and links against hipThreads.
For installation instructions, see :doc:`/install/install`.

Set up your ``CMakeLists.txt``
******************************

Follow the steps below to create a minimal ``CMakeLists.txt`` that builds a HIP application with hipThreads.

1. Declare the project with HIP language support
------------------------------------------------

hipThreads code runs on AMD GPUs through HIP, so the project must declare HIP as an enabled language.
Set the C++ standard to 17 or later with ``CMAKE_HIP_STANDARD``:

.. code-block:: cmake

   cmake_minimum_required(VERSION 3.21)
   project(my_app LANGUAGES HIP)

   set(CMAKE_HIP_STANDARD 17)

2. Find the hipThreads package
------------------------------

Use ``find_package()`` to locate the hipThreads CMake configuration files:

.. code-block:: cmake

   find_package(hipthreads REQUIRED)

3. Link your target against hipThreads
--------------------------------------

Create the executable or library and link it to the ``hipthreads::hipthreads`` imported target:

.. code-block:: cmake

   add_executable(my_app main.hip)
   target_link_libraries(my_app hipthreads::hipthreads)

Complete minimal example
************************

Putting it all together, a complete ``CMakeLists.txt`` looks like this:

.. code-block:: cmake

   cmake_minimum_required(VERSION 3.21)
   project(my_app LANGUAGES HIP)

   set(CMAKE_HIP_STANDARD 17)

   find_package(hipthreads REQUIRED)

   add_executable(my_app main.hip)
   target_link_libraries(my_app hipthreads::hipthreads)

Configure and build the project
*******************************

Run CMake from the project directory:

.. code-block:: shell

   cmake -B build
   cmake --build ./build

Use ``CMAKE_PREFIX_PATH`` when hipThreads isn't under ``ROCM_PATH``
*******************************************************************

When hipThreads is installed as part of AMD ROCm, CMake typically finds it automatically.
If hipThreads is installed to a custom location that isn't under ``$ROCM_PATH``, pass its install prefix through ``CMAKE_PREFIX_PATH``:

.. code-block:: shell

   cmake -B build -DCMAKE_PREFIX_PATH=hipthreads_install_prefix

Combine multiple prefixes by separating them with a semicolon in the shell command:

.. code-block:: shell

   cmake -B build -DCMAKE_PREFIX_PATH="hipthreads_install_prefix;other_dep_prefix"
