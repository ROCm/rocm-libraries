Detailed Description

Condition variable that works with any BasicLockable lock.

Maintains separate counters for waiters and notifications. Each wait() obtains an arrival index; notify operations advance a notification counter.

Note
Not copyable or movable.
Warning
Implementation spins while waiting; avoid long waits to prevent excessive resource usage.

void hip::condition_variable_any::wait ( _Lock &  __lock)

Blocks (spins) until notified.

Atomically:

  1. Records arrival index.
  2. Releases the supplied lock (lock.unlock()).
  3. Spins until its index is < current notify counter.
  4. Reacquires the lock before returning.
