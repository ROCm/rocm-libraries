*********************************
Port a ray tracer from CPU to GPU
*********************************

This tutorial walks through the ``examples/InOneWeekendRaytracer/`` example,
based on Peter Shirley's *Ray Tracing in One Weekend*. The program renders a
random scene to a PPM image and progresses across four steps:

- ``step1-baseline/main.cc``, single-threaded row partitioning on the CPU
- ``step2-cpu-optimizations-tiling/main.cc``, 8×4 tile scheduling on the CPU
- ``step3-hipthread-dropin/main.hip``, ``hip::wthread`` GPU port
- ``step4-simdize/main.hip``, one SIMD fiber per pixel inside each tile

For background on porting and memory management, see
:doc:`/conceptual/porting-from-std-thread` and
:doc:`/conceptual/gpu-memory-model`.

Step 1: CPU baseline
********************

``step1-baseline/main.cc`` splits scanlines across
``std::thread::hardware_concurrency()`` workers. Each thread receives a
contiguous row range and accumulates color samples per pixel:

.. code-block:: cpp

   const int k_threads = std::thread::hardware_concurrency();
   std::vector<std::thread> threads(k_threads);
   for (int t = 0; t < k_threads; ++t) {
       threads[t] = std::thread(std::bind([&](int start, int end, int t) {
           for (int j = start; j < end; j++) {
               for (int i = 0; i < nx; i++) {
                   vec3 col(0, 0, 0);
                   for (int s = 0; s < ns; s++) {
                       float u = float(i + random_double()) / float(nx);
                       float v = float(j + random_double()) / float(ny);
                       ray r = cam.get_ray(u, v);
                       col += color(r, world, 0);
                   }
                   // ... write gamma-corrected pixel to image ...
               }
           }
       }, t * ny / k_threads,
          (t + 1) == k_threads ? ny : (t + 1) * ny / k_threads, t));
   }

The scene and image buffer both live in host memory.

Step 2: CPU tile scheduling
***************************

``step2-cpu-optimizations-tiling/main.cc`` refactors the outer loop to assign
8×4 pixel tiles instead of full rows. Threads stride across tile indices,
which improves cache locality on the CPU:

.. code-block:: cpp

   const int tx = 8;
   const int ty = 4;
   const int tiles_x = (nx + tx - 1) / tx;
   const int tiles_y = (ny + ty - 1) / ty;
   const int total_tiles = tiles_x * tiles_y;

   threads[t] = std::thread([&, t] {
       for (int tile_idx = t; tile_idx < total_tiles; tile_idx += k_threads) {
           int tile_x = tile_idx % tiles_x;
           int tile_y = tile_idx / tiles_x;
           int i_start = tile_x * tx;
           int j_start = tile_y * ty;
           for (int j = j_start; j < j_start + ty && j < ny; ++j) {
               for (int i = i_start; i < i_start + tx && i < nx; ++i) {
                   // ... trace rays and write pixel ...
               }
           }
       }
   });

Step 2 also replaces recursive ``color()`` with an iterative loop, which
avoids deep call stacks during tracing.

Step 3: ``hip::wthread`` GPU drop-in
*************************************

``step3-hipthread-dropin/main.hip`` moves the scene and framebuffer into
device memory and replaces ``std::thread`` with ``hip::wthread``.

Device-resident scene
---------------------

The ``hittable_list`` scene is placement-new'd on the device before rendering
starts and explicitly destroyed after all render threads join:

.. code-block:: cpp

   thrust::device_ptr<hittable_list> dev_ptr_world =
       thrust::device_malloc<hittable_list>(1);
   hittable_list *world = thrust::raw_pointer_cast(dev_ptr_world);

   {
       hip::wthread world_constructor(
           [=] __device__ () { new (world) hittable_list(random_scene()); });
       world_constructor.join();
       // ... render threads ...
       hip::wthread([=] __device__ () { world->~hittable_list(); }).join();
   }

Per-pixel random state
----------------------

Global ``random_double()`` on the host becomes a per-pixel ``hiprandState`` on
the device. Each pixel seeds its own generator before sampling anti-aliasing
offsets:

.. code-block:: cpp

   hiprandState randState;
   setup_random(j * nx + i + 1, &randState);
   float u = float(i + random_double(&randState)) / float(nx);
   float v = float(j + random_double(&randState)) / float(ny);
   ray r = cam.get_ray(u, v, &randState);
   col += color(r, *world, &randState);

Tile-parallel render threads
----------------------------

The tile loop from step 2 is preserved. The example launches 4096
``hip::wthread`` instances, each striding across ``total_tiles``:

.. code-block:: cpp

   threads[t] = hip::wthread([=, image = image_d.get_raw()] __device__ () {
       for (int tile_idx = t; tile_idx < total_tiles; tile_idx += k_threads) {
           // ... iterate pixels in tile, trace rays, write image ...
       }
   });

After all threads join, ``thrust::copy`` moves the framebuffer to the host
for PPM output.

Step 4: SIMD fiber-width optimization
*************************************

``step4-simdize/main.hip`` passes ``hip::wthread::max_width()`` so each
``hip::wthread`` runs as a cooperative SIMD block. All fibers in a block work
on the same tile. Each fiber traces one pixel inside the 8×4 tile:

.. code-block:: cpp

   threads[t] = hip::wthread(hip::wthread::max_width(),
       [=, image = image_d.get_raw()] __device__ () {
           for (int tile_idx = t; tile_idx < total_tiles; tile_idx += k_threads) {
               int tile_x = tile_idx % tiles_x;
               int tile_y = tile_idx / tiles_x;
               int i_start = tile_x * tx;
               int j_start = tile_y * ty;

               int j = j_start + hip::this_thread::get_fiber_id() / tx;
               int i = i_start + hip::this_thread::get_fiber_id() % tx;
               if (j >= ny || i >= nx) continue;

               // ... trace one pixel with per-fiber randState ...
           }
       });

An 8×4 tile holds 32 pixels, which matches typical SIMD width on AMD GPUs.

Build and run
*************

For installation instructions, see :doc:`/install/install`.

Build any step from its directory:

.. code-block:: bash

   cd examples/InOneWeekendRaytracer/step3-hipthread-dropin
   cmake -B build
   cmake --build ./build
   ./build/bin/inOneWeekend > image.ppm

Repeat for the other step directories. Each binary writes a PPM image to
standard output.

See :doc:`/reference/thread-management` for ``max_width()``,
``get_fiber_id()``, and ``get_width()``. To tune scheduler concurrency, see
:doc:`/how-to/tune-scheduler-concurrency`.
