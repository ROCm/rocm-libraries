**************************
Port SAXPY from CPU to GPU
**************************

This tutorial walks through the ``examples/saxpy/`` example in the hipthreads
repository. The program computes a repeated SAXPY operation,
``y[i] = alpha * x[i] + y[i]``, over a large vector and progresses across
three steps from CPU ``std::thread`` parallelism to a SIMD-width-optimized
``hip::wthread`` GPU port.

The complete source lives in three step directories:

- ``step1-baseline/main.cxx``, CPU baseline with ``std::thread``
- ``step2-hipthread-dropin/main.hip``, drop-in ``hip::wthread`` port
- ``step3-simdize/main.hip``, multi-fiber execution with ``max_width()``

For the porting model, see :doc:`/conceptual/porting-from-std-thread`. For
device memory setup, see :doc:`/conceptual/gpu-memory-model`. For the full
``hip::wthread`` API, see :doc:`/reference/thread-management`.

Step 1: CPU baseline with ``std::thread``
*****************************************

``step1-baseline/main.cxx`` stores ``x`` and ``y`` in host ``std::vector``
buffers and partitions the ``N`` elements across ``std::thread::hardware_concurrency()``
workers. Each thread receives a chunk size, an offset, and raw pointers into
the host vectors:

.. code-block:: cpp

   std::vector<std::thread> threads(std::thread::hardware_concurrency());

   for (unsigned int i = 0; i < threads.size(); ++i) {
       size_t chunk_size = (i < N % threads.size()) ? (N / threads.size() + 1)
                                                    : (N / threads.size());
       size_t offset = (i < N % threads.size()) ? (i * chunk_size)
                                                : (i * chunk_size + N % threads.size());

       threads[i] = std::thread(
           [] (uint32_t n, float a, const float *x, float *y) {
               for (uint32_t i = 0; i < n; ++i) {
                   float t = x[i];
                   for (int j = 0; j < NUM_ITERATIONS; ++j) {
                       t = a * t + y[i];
                   }
                   y[i] = t;
               }
           },
           chunk_size, alpha, x.data() + offset, y.data() + offset);
   }

The inner loop repeats the SAXPY update ``NUM_ITERATIONS`` times to amplify
compute time for benchmarking.

Step 2: drop-in ``hip::wthread`` port
*************************************

``step2-hipthread-dropin/main.hip`` keeps the same chunking logic but moves
execution to the GPU. The main changes are:

Device buffers
--------------

Host vectors are copied into device memory with Thrust before any
``hip::wthread`` enters scope:

.. code-block:: cpp

   thrust::unique_ptr<float[]> x = thrust::make_unique<float[]>(N);
   thrust::unique_ptr<float[]> y = thrust::make_unique<float[]>(N);
   thrust::copy(x_host.begin(), x_host.end(), x.get());
   thrust::copy(y_host.begin(), y_host.end(), y.get());

``hip::wthread`` scope
----------------------

All ``hip::wthread`` objects must join before the persistent scheduler kernel
exits. The example wraps them in a scoped block:

.. code-block:: cpp

   { // hip::wthread scope starts here
       std::vector<hip::wthread> threads(hip::wthread::hardware_concurrency());
       // ...
       for (auto &t : threads) {
           t.join();
       }
   } // hip::wthread scope ends here

Thread launch
-------------

``std::thread`` becomes ``hip::wthread``, the lambda gains ``__device__``, and
arguments pass device pointers from ``get_raw()``:

.. code-block:: cpp

   threads[i] = hip::wthread(
       [] __device__(uint32_t n, float a, const float *x, float *y) {
           for (uint32_t i = 0; i < n; ++i) {
               float t = x[i];
               for (int j = 0; j < NUM_ITERATIONS; ++j) {
                   t = a * t + y[i];
               }
               y[i] = t;
           }
       },
       chunk_size, alpha, x.get_raw() + offset, y.get_raw() + offset);

``hip::wthread::hardware_concurrency()`` reports scheduler slot count on the
GPU, which is typically much larger than CPU core count.

After the threads join, ``thrust::copy`` moves ``y`` back to the host for
verification.

Step 3: SIMD multi-fiber execution
**********************************

``step3-simdize/main.hip`` passes ``hip::wthread::max_width()`` as the first
constructor argument. Each ``hip::wthread`` then runs as a cooperative block
whose fibers share the same chunk. Inside the lambda, ``get_fiber_id()`` and
``get_width()`` stride the element loop across SIMD lanes:

.. code-block:: cpp

   threads[i] = hip::wthread(hip::wthread::max_width(),
       [] __device__(uint32_t n, float a, const float *x, float *y) {
           for (uint32_t i = hip::this_thread::get_fiber_id(); i < n;
                i += hip::this_thread::get_width()) {
               float t = x[i];
               for (int j = 0; j < NUM_ITERATIONS; ++j) {
                   t = a * t + y[i];
               }
               y[i] = t;
           }
       },
       chunk_size, alpha, x.get_raw() + offset, y.get_raw() + offset);

This pattern suits element-wise kernels where adjacent indices have no data
dependencies.

Build and run
*************

For installation instructions, see :doc:`/install/install`.

Build each step from its directory:

.. code-block:: bash

   cd examples/saxpy/step1-baseline
   cmake -B build
   cmake --build ./build
   ./build/bin/saxpy

Repeat for ``step2-hipthread-dropin`` and ``step3-simdize``. Each binary
prints wall-clock time in nanoseconds and validates the result against the
closed-form expected value.

To tune scheduler slot count for your GPU, see
:doc:`/how-to/tune-scheduler-concurrency`.
