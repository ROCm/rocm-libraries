# hipCCL docs

The hipCCL-level documentation is in [`../../docs/`](../../docs/index.rst), and
is shared by the `hipccl3` and `hipccl2` layouts. Build it with `BUILD_DOCS=ON`
or see [`../../README.md`](../../README.md#building-the-documentation-locally).

Each component keeps its own documentation:

- [`../rocprim/docs/`](../rocprim/docs/)
- [`../hipcub/docs/`](../hipcub/docs/)
- [`../rocthrust/docs/`](../rocthrust/docs/)
- [libhipcxx `docs/`](https://github.com/ROCm/libhipcxx/tree/amd-develop/docs) (separate repository, `ROCm/libhipcxx`)
