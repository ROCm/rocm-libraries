*************************
hipCCL documentation
*************************

hipCCL is AMD's unified package for `rocPRIM <https://rocm.docs.amd.com/projects/rocPRIM/en/latest/index.html>`_, `hipCUB <https://rocm.docs.amd.com/projects/hipCUB/en/latest/index.html>`_, and `rocThrust <https://rocm.docs.amd.com/projects/rocThrust/en/latest/index.html>`_.

The hipCCL project is located in `ROCm/rocm-libraries <https://github.com/ROCm/rocm-libraries/tree/develop/projects/hipccl>`_.
