=======================
Primbench documentation
=======================

primbench is a single-header C++ benchmarking library for HIP and CUDA GPU workloads. It provides a simple API for writing GPU microbenchmarks with built-in noise reduction, GPU warming and cooling, cache clearing, correctness assertions, and detailed JSON and CSV output. primbench supports AMD GPUs via HIP (with optional AMD SMI temperature monitoring) and NVIDIA GPUs via CUDA (with optional NVML monitoring), and runs on both Linux and Windows.

The Primbench public repository is located at
`ROCm/rocm-libraries <https://github.com/ROCm/rocm-libraries/tree/develop/shared/primbench>`_.
