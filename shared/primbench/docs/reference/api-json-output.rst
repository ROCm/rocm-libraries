===========
JSON output
===========

The ``json`` class is a lightweight JSON builder passed to :doc:`benchmark_interface::meta() </reference/api-benchmark-interface>` so that each benchmark specialization can describe itself with algorithm names, type names, and custom fields. These key–value pairs appear in the output ``results.json`` file.

For details on the structure of the generated JSON file, see :doc:`/conceptual/output-format`.
