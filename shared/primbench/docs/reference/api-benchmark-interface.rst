====================================
Benchmark interface and executor API
====================================

This page documents the core types for defining and running GPU benchmarks with Primbench: the ``benchmark_interface`` base class, the ``executor`` that drives benchmark runs, the ``settings`` struct that controls tunable parameters, and the ``flags`` utilities. For the ``state`` object passed into your benchmark's ``run()`` method, see :doc:`Benchmark state API </reference/api-benchmark-state>`. For command-line option details, see :doc:`Command-line options </reference/cli-options>`.

Command-line values override any programmatic ``settings`` values passed to the ``executor`` constructor.
