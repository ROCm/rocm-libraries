=================
Install primbench
=================

Primbench is a single-header library. No build step, package installation, or linking against a Primbench binary is required. You include the header in your project, compile with ``hipcc`` or ``nvcc``, and run.

Prerequisites
*************

Required
--------

- **HIP or CUDA** — ``hipcc`` (shipped with AMD ROCm) or ``nvcc`` (shipped with the NVIDIA CUDA toolkit).
- **C++17 or later** — Primbench requires a C++17-capable compiler.

Optional (recommended)
----------------------

For GPU temperature monitoring, which keeps the GPU in a stable temperature range and reduces benchmark noise:

- **AMD SMI** (``libamd_smi``) — HIP only, not available on Windows. Typically included with AMD ROCm. See the `AMD SMI documentation <https://rocm.docs.amd.com/projects/amdsmi/en/latest/>`_ for details.
- **NVML** (``libnvidia-ml``) — CUDA only. Ships with NVIDIA drivers.

.. important::

   If AMD SMI (HIP) or NVML (CUDA) is not available — for example on Windows — or if you choose not to link against these libraries, you **must** disable GPU monitoring by adding the following flag when compiling:

   .. code-block:: shell

      -DPRIMBENCH_NO_MONITORING

Obtaining the header
********************

Primbench consists of a single header file, ``primbench.hpp``. Place it anywhere your compiler can find it via an ``-I`` include path.

You can clone the repository and point your compiler at the repository root:

.. code-block:: shell

   git clone https://github.com/ROCm/rocm-libraries.git
   cd rocm-libraries

Then pass ``-I.`` (or the appropriate path to the directory containing ``primbench.hpp``) when compiling.

Alternatively, copy ``primbench.hpp`` directly into your project's include directory.

Compiling a benchmark
*********************

Because Primbench is header-only, the compile command for your benchmark is all that is needed. The examples below show how to compile a benchmark source file.

Compiling with HIP on Linux
---------------------------

.. code-block:: shell

   hipcc -o copy_benchmark examples/hip/copy_benchmark.cpp -I. -lamd_smi && ./copy_benchmark

The ``-lamd_smi`` flag links AMD SMI for GPU temperature monitoring. The ``-I.`` flag adds the current directory (containing ``primbench.hpp``) to the include search path.

Compiling with HIP on Windows
-----------------------------

On Windows, AMD SMI is not available, so you must disable monitoring:

.. code-block:: shell

   hipcc -o copy_benchmark.exe examples/hip/copy_benchmark.cpp -I. -DPRIMBENCH_NO_MONITORING -std=c++17 -g --offload-arch=$(amdgpu-arch) ; ./copy_benchmark.exe

Compiling with CUDA on Linux
----------------------------

.. code-block:: shell

   nvcc -o copy_benchmark examples/cuda/copy_benchmark.cu -I. -lnvidia-ml && ./copy_benchmark

The ``-lnvidia-ml`` flag links NVML for GPU temperature monitoring.

Disabling monitoring at compile time
************************************

When neither AMD SMI nor NVML is available, or when you prefer not to use temperature-based warming and cooling, compile with the ``-DPRIMBENCH_NO_MONITORING`` preprocessor flag. Without this flag and without the monitoring library, compilation fails.

.. code-block:: shell

   -DPRIMBENCH_NO_MONITORING

This flag works with both ``hipcc`` and ``nvcc``.
