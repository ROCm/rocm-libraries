# ROCm Python bindings

Each directory is an independently buildable Python package using installed
ROCm libraries. Native components build without these packages.

See [RFC0019: Custom Python Bindings Layering](https://github.com/ROCm/TheRock/pull/6050)
for build, loading, validation, and release requirements. The RFC is under review.

- [rocm-origami](rocm-origami): Origami analytical GEMM selection bindings.
