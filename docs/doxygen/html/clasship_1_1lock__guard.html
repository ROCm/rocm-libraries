Detailed Description

template<class _Mutex>
class hip::lock_guard< _Mutex >

Scoped non-copyable guard that owns a mutex for its lifetime.

Template Parameters
_MutexMutex type meeting BasicLockable (lock(), unlock()).

Guarantees:

  • Acquires the mutex in the locking constructor.
  • Releases the mutex in the destructor.
  • Non-copyable and non-assignable to prevent multiple owners.
