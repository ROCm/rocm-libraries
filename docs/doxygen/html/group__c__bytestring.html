const void *  src,

)
inline

Copies a block of memory from a source address to a destination address.

Copies count bytes from the object pointed to by src to the object pointed to by dest. Both objects are reinterpreted as arrays of unsigned char.

This version is available for use in both __host__ and __device__ code.

Warning
The behavior is undefined if the memory areas of src and dest overlap.
Parameters
destPointer to the destination array where the content is to be copied.
srcPointer to the source of data to be copied.
countNumber of bytes to copy.
Returns
A copy of dest.
