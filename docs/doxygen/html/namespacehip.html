_L1 &  __l1

try_lock for two mutex-like objects.

Attempts to lock __l0 (non-blocking) then __l1 (non-blocking). On success both are locked and -1 is returned. On failure:

  • Return 0 if __l0 could not be locked.
  • Return 1 if __l0 locked but __l1 failed (and __l0 is released).
Returns
int Index of the first mutex that failed, or -1 if all locked.

try_lock for N >= 3 mutex-like objects.

Attempts to lock the first mutex then recursively tries the remainder. On failure the already-locked subset is released (strong exception / failure safety).

Returns
int Index (0-based) of first mutex that failed, or -1 if all locked.
