unsigned int hip::this_thread::get_fiber_id ( )
noexcept

Returns the current fiber's unique identifier within this thread.

Returns
Zero-based fiber index, stable within the lifetime of the work unit.

Commonly used for loop indexing and work distribution across fibers. Example: for (uint32_t i = get_fiber_id(); i < n; i += get_width())
