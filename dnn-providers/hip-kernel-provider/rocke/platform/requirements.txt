# rocKE engine - Python requirements
#
# The pure IR build + LLVM-IR lowering path (rocke.core) needs only the Python
# standard library and ctypes, so the byte-identity gate and most unit tests run
# with no third-party packages. The entries below cover authoring, building the
# C++ engine binding, on-GPU launch/numeric, and the test harness.
#
# ROCm is NOT a pip package and cannot be pinned here. It is a system dependency
# (libamd_comgr, libamdhip64, hipcc/amdclang) that must be installed separately.
#   Required:    ROCm with comgr + HIP discoverable by the dynamic linker; the
#                recommended release is in dsl_docs/development/setup_guide.md §1.
#                AUTO queries the loaded COMGR compiler to select the LLVM IR
#                flavor; package-release metadata is not that evidence.
# Torch is NOT listed: rocKE does not depend on it, and its remaining uses are
# being removed. One that still needs it takes a ROCm torch wheel matching the
# system ROCm, installed separately (the default PyPI wheel is CPU-only).

# --- on-GPU launch + numeric reference (ROCm) --------------------------------
numpy>=1.24

# --- building the rocke_engine pybind module (cpp/bindings) --------------------
# pybind11 is in pyproject.toml's dev extra, not here: these requirements also
# go into the hipDNN superbuild's build Python, and a provider build uses no
# pybind11 (ROCKE_BUILD_PYBIND stays OFF there).

# --- test / dev --------------------------------------------------------------
# pytest 9 runs subtests itself; rocke.tests.sweep_guard needs its subtest reports.
pytest>=9.0
pytest-timeout>=2.4
# Independent FP4/FP6/FP8 reference types:
ml_dtypes>=0.5.0
