# gfx942

`has_ds_read_tr=false`. f16 MFMA 16×16×16 and 32×32×8; fp8 MFMA 16×16×32 /
32×32×16. No f16 K-pack 16×16×32 (that is gfx950). VGPR 512, AGPR 256.
