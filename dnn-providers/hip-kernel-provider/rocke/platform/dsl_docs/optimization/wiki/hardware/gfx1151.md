# gfx1151

RDNA3.5, wave32, WMMA 16×16×16 f16/bf16 (+ iu8/iu4). VGPR 256, AGPR 0, 64 KiB
LDS, no async LDS / ds_read_tr. Rocke portable GEMM: `mem` + `default` only.
Reductions must use `wave_size=32`.
