# gfx1250

CDNA-class **product** on the **GFX12 programming model**: wave32, WMMA (no
MFMA), AGPR 0, 160 KiB LDS (`lds_capacity_bytes: 163840`), `vgprs: 256`.
SSOT: `platform/python/rocke/core/arch/data/arch_specs.json`.

Catalog flags that stay **false on purpose**: `has_mfma`, `has_async_lds`,
`has_ds_read_tr`, `has_tdm`. Those bits admit the gfx950 MFMA tiled builder.
gfx1250 async/transpose are distinct GFX12 opcodes (`has_async_global_lds`,
`ds_load_tr16_b128`).

Deferred in the ISA backend (do not assume they emit): 57-bit buffer SRD
packing, a full split-waitcnt encoding for generic `s_waitcnt`. LDS-barrier
drain **does** emit `s_wait_loadcnt` / `s_wait_dscnt`. Shader-end padding is
required in the catalog (`requires_shader_end_padding: true`).

## KernelWiki Blackwell analog (programming-model only)

gfx1250 is **not** SM100. The table is a routing aid: same *job*, different
opcode and ownership. Never copy PTX or TFLOP/s.

| Blackwell page (KernelWiki) | gfx1250 analog | Not the same |
|---|---|---|
| `tcgen05.mma` | `hw-wmma-gfx1250` | Per-wave WMMA; D in VGPR, not TMEM |
| TMEM | `hw-vgpr-acc-gfx1250` | No dedicated tensor memory; AGPR=0 |
| TMA | `hw-async-global-lds` | No tensor-map descriptor |
| mbarrier tx-count | `hw-asynccnt` + `hw-split-waitcnt` | Dedicated ASYNCcnt + split load/ds |
| CLC | none in catalog | Software tile schedule only |
| PDL / GDC | none in catalog | — |
| NVFP4 / mx block-scale MMA | `hw-fp8-wmma-gfx1250` | fp8 K=64; F4/block16 **omitted** |
| `cta_group::2` 2-SM MMA | `hw-cluster-barrier` | Named/cluster barriers; no paired-CTA WMMA |
