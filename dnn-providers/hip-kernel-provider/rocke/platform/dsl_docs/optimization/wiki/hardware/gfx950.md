# gfx950

Default rocke target. Wave64, 160 KiB LDS, 64 banks, `has_ds_read_tr=true`,
`vmcnt_bits=6`. f16/bf16 K-pack 16×16×32 and 32×32×16; fp4/fp6/MX MFMA in the
catalog. Preferred LDS swizzle: padding (not XOR).

Deeper narrative: `arch/gfx950.md`. Backend: production llvm22+comgr; occupancy
stories are flavor-sensitive.
